BYESHRIMP / 隐私

隐私政策

生效日期：2026年10月12日

ByeShrimp 开发者重视您的隐私。本政策说明 ByeShrimp iOS 应用在您的设备上处理的信息、通过 Apple 处理的购买信息，以及联系开发者的方式。

1. 运营者与适用范围

本政策适用于 ByeShrimp 应用及本网站。运营者为 ByeShrimp 开发者（ABBY-0419）。本应用的设计无需开发者运营的账户服务器或数据收集服务器即可运行。

2. 应用处理的信息

AirPods 运动信息

当您授予 iOS“运动与健身”权限并启动提醒时段后，应用会使用受支持 AirPods 的运动信息来判断您登记的姿势。传感器样本和实时匹配状态仅在时段内于设备内存中处理，不会发送到开发者服务器。

已保存的姿势和设置

您选择的姿势名称、参考方向及相关检测设置会保存在设备上，以提供应用功能。最多可保存三个姿势，并可在应用中编辑或删除。

通知和购买

时段状态提醒使用 iOS 本地通知。本应用不会创建推送通知令牌，也不使用自有通知服务器。试用和永久使用权购买通过 Apple App Store 的 StoreKit 处理。应用会核验 Apple 提供的交易信息以判断使用权限。付款信息由 Apple 处理，应用开发者不会收到您的银行卡号。

3. 使用目的和保存期限

  • 运动信息用于当前检测时段内的姿势匹配和提醒。时段结束后，实时样本会从内存中释放。
  • 已保存的姿势和设置保留在设备上，以便您重新打开应用时继续使用；在您删除这些内容或移除应用数据前会一直保留。
  • Apple 交易记录用于购买验证和恢复。Apple 的保存方式受 Apple 的条款和隐私政策约束。
  • 如果您通过电子邮件联系开发者，邮件可能会在电子邮件服务和邮箱中保留至回复所需的时间。本应用没有独立的联系表单或客户数据库。

4. 共享和外部服务

本网站托管于 GitHub Pages。为提供和保护网站，GitHub 可能会处理 IP 地址、浏览器或设备信息、请求日志等技术信息。开发者不运营独立的网站访问分析服务。详情请参阅 GitHub 隐私声明。

开发者不会出售应用处理的信息，也不会为广告或分析目的向第三方共享。Apple 根据其自身政策处理 iOS 权限、App Store 购买和操作系统服务。详情请参阅 Apple 隐私政策。

本应用不包含由开发者运营的分析 SDK、广告 SDK、用户账户或自有服务器传输功能。

5. 您的选择和删除

您可以在 iOS 设置中更改“运动与健身”权限，在应用中删除已登记的姿势，并在设备上管理应用设置。购买恢复和 Apple 账户请求请使用 Apple 的流程。由于姿势数据和传感器记录不会存储在开发者服务器上，因此开发者没有可供导出或删除的此类服务器数据。

6. 安全

已保存的姿势信息和设置保存在应用的设备内存储中，实时传感器样本在内存中处理。设备密码、操作系统安全和备份行为取决于您的设备设置。直接发送的电子邮件会经过您的电子邮件服务提供商系统。

7. 政策变更

如果应用功能或适用要求发生变化，我们会更新本页面并修改生效日期。重要变更也可能通过应用更新或公开网站通知。
